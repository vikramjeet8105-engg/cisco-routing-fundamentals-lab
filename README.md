# Routing fundamentals (Packet Tracer)

| File | Lab |
|---|---|
| `lab0.pkt`, `lab1.pkt` | Introductory topologies: device setup and basic router and switch configuration |
| `lab2-serial-wan-links.pkt` | Synchronous serial WAN links between routers |
| `lab3-subnetting-vlsm-design.pkt` | Subnetting 192.168.100.0/24 into five subnets and addressing the topology |
| `lab5-rip-dynamic-routing.pkt` | RIPv2 dynamic routing and comparison with RIPv1 |
| `practice-all-labs.pkt` | Practice topology combining the exercises above |
